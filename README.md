## 🧱 네온 벽돌깨기

패들로 공을 튕겨 벽돌을 모두 깨는 게임이에요. 다 깨면 다음 레벨로 넘어가고, 레벨이 오를수록 공이 빨라져요.

- 목숨 ❤️ 3개, 벽돌 하나에 10점
- 아이템: 🟢 초록 = 패들 길어짐 / 🟡 노랑 = 공 추가
- 최고 점수와 닉네임 순위 TOP 10 저장

| 할 일 | PC | 휴대폰 |
| --- | --- | --- |
| 패들 움직이기 | ← → 방향키 또는 마우스 | 화면을 손가락으로 좌우로 끌기 |
| 소리 켜기/끄기 | 오른쪽 위 🔊 버튼 | 오른쪽 위 🔊 버튼 |

## 🏝️ 섬 지뢰찾기

40×30칸 풀밭 아래에 지뢰 150개가 숨어 있어요. 지뢰 주변은 **땅**, 나머지는 **바다**예요. 땅에 적힌 숫자는 주변 8칸에 있는 지뢰 개수예요.

- 바다를 열면 이어진 바다가 한 번에 열려요
- 지뢰를 밟으면 게임 오버, 지뢰가 아닌 칸을 모두 열면 클리어!
- 클리어 시간 기록과 닉네임 순위 TOP 10 저장

| 할 일 | PC | 휴대폰 |
| --- | --- | --- |
| 풀 없애기 | 왼쪽 클릭 | 톡 누르기 |
| 깃발 🚩 꽂기 | 오른쪽 클릭 | 길게 누르기 또는 ⛏️/🚩 버튼 |
| 판 움직이기 | (판 전체가 보여요) | 손가락으로 끌기 |
| 크게/작게 보기 | −/+ 버튼 | −/+ 버튼 |

> 💾 최고 기록과 순위는 각자의 기기와 브라우저에 저장돼요.
